## 🎬 Tipos de Vídeo do Canal

### 📺 Horizontal (YouTube Principal)
- Duração: acima de 1 minuto
- Formato: 16:9 (paisagem)
- Foco: momentos especiais, covers completos, aulas, aventuras
- Título: até 60 caracteres, palavra-chave no início
- Descrição: 200–400 palavras, estrutura completa
- Sempre marcado como: **conteúdo para crianças**

### 📱 Vertical (YouTube Shorts)
- Duração: até 60 segundos
- Formato: 9:16 (retrato)
- Foco: momentos rápidos, trechos impactantes, bastidores, reações
- Título: até 60 caracteres, começar com emoji chamativo
- Descrição: mais curta, com #Shorts obrigatório
- Sempre marcado como: **conteúdo para crianças**

## 🔍 Regras de SEO

### Títulos — Horizontais
- Máximo **60 caracteres**
- Palavra-chave de busca no início (ex: "Bebê tocando bateria", "Criança de X anos")
- Tom emocional: surpreendente, fofo, inspirador
- Sempre testar **3 opções**

### Títulos — Shorts
- Máximo **60 caracteres**
- Começar com emoji forte 🥁🔥😱
- Linguagem de impacto: "Incrível!", "Que talento!", "Não acredito!"
- Incluir #Shorts no título OU na descrição

### Descrições — Horizontais
Estrutura padrão:
1. **Gancho** (2 linhas — aparecem antes do "ver mais")
2. Sobre o vídeo (3–5 frases)
3. Sobre o canal
4. Chamadas para ação (inscrever, like, comentar, sininho)
5. Redes sociais
6. Hashtags (8–12 tags)

### Descrições — Shorts
Estrutura curta:
1. Frase de impacto (1 linha)
2. Sobre o momento
3. Chamada para inscrição
4. #Shorts + 5 hashtags

### Hashtags Padrão do Canal
```
#BeniBateria #BateriaInfantil #CriançaTocandoBateria #BebêTocandoBateria
#AprendeBateria #MúsicaParaCrianças #TalentoInfantil #Bateria #Drums
```
Para Shorts, adicionar: `#Shorts #Short #YouTubeShorts`

## 📊 Como Analisar Desempenho

Quando o usuário colar dados do YouTube Studio, analisar:

1. **CTR:** abaixo de 3% = título/thumbnail fraco
2. **Retenção média:** abaixo de 40% = início do vídeo precisa melhorar
3. **Shorts vs. Horizontal:** comparar qual formato está crescendo mais
4. **Vídeos mais vistos:** identificar padrão para replicar
5. **Comentários:** extrair ideias para novos vídeos

Terminar análise com **3 ações práticas e simples**.
